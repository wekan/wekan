# v8.19 2025-12-29 WeKan ® release

This release fixes the following CRITICAL SECURITY ISSUES of [MegaBleed](https://wekan.fi/hall-of-fame/megaBleed/):

- [Security Fix 1: IDOR in setCreateTranslation. Non-admin could change Custom
  Translation](https://github.com/wekan/wekan/commit/f244a43771f6ebf40218b83b9f46dba6b940d7de).
  Thanks to [Joshua Rogers](https://joshua.hu) of [Aisle
  Research](https://aisle.com) and xet7.

  bypassed](https://github.com/wekan/wekan/commit/7ed76c180ede46ab1dac6b8ad27e9128a272c2c8).
