# All Boards and personal pages

Open **All Boards** from the home control or username menu. Select the workspace
and board category in the left menu; links identify the selected page so it can
be bookmarked. Open a board by its title. Access still follows board membership
and public/private visibility.

- [All Boards](All-Boards.md): overview, sorting and board actions
- [Workspaces](Workspaces.md): workspace choices and roles
- [Public](Public.md): public boards and favorites
- [Starred](../Pages/Starred.md): starred boards and items
- [Page URLs](URLs.md): direct links and navigation
- [Archives](Archive.md): archived content
- [My Cards, Due Cards and My Attachments](../Pages/My-Cards-Due-Attachments.md)
- [Templates](Templates.md)

The signed-in Public page keeps favorite public boards in the user's profile,
so they remain selected after a reload. Starring does not grant private-board
access or change board membership.
