# Board Settings / Date

A board administrator opens **Right sidebar / Board Settings / Date**.
The top of the popup shows whether the global Date Format is enabled and its
saved value. Check the board override, choose a format, and **Save**. Unchecking
it makes the board inherit the global setting. A member's enabled personal
format takes precedence over both.

Below **Save** and the horizontal rule, **Show week of year (ISO 8601)** toggles
your own week-number display immediately; it does not set a format for everyone.
See [all three date scopes and the member controls](../../Member-Settings/Date/README.md).
