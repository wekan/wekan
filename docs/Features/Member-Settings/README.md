# Member Settings

Click your username or avatar at the **top right**. Entries depend on your
account type, role and site settings. In menu order:

| Entry | What to use it for |
| --- | --- |
| My Cards | [Cards associated with you](My-Cards-Due-Attachments.md) |
| Due Cards | [Cards with deadlines](My-Cards-Due-Attachments.md) |
| My Attachments | [Your attachments](My-Cards-Due-Attachments.md) |
| Starred | [Favorite boards and items](../All-Boards/Starred.md) |
| Global Search | [Search across accessible content](../Page/Search.md) |
| All Boards | [Board overview](../All-Boards/README.md) |
| Public | [Public boards](../All-Boards/Public.md) |
| Archives | [Archived content](../Page/Archive.md) |
| Help | The site's configured help link, when provided |
| Templates | [Reusable content](../Board/Templates.md) |
| Admin Panel | [Administration](../Admin-Panel/Admin-Panel.md), for authorized administrators |
| Invite People | Invite people when site settings allow it |
| Edit Profile | Your account details; availability depends on authentication |
| Date | [Date format, week start and calendar system](Date/README.md) |
| Change Settings | [Editing and display preferences](Change-Settings.md) |
| Change Color | [Appearance](../Theme/Theme.md) |
| Notifications | [Email and in-app delivery preferences](Notifications.md) |
| Change Font | Choose the font used for your display |
| Change Avatar | Change your profile image, if uploads are allowed |
| Change Password | Change a local account's password |
| Two-Factor Authentication | [Set up an authenticator](../Login/Two-Factor-Authentication.md) |
| Change Language | [Language chooser](Change-Language.md) |
| Support | The site's configured support link, when provided |
| Log out | End your session; Sandstorm manages its own session |

Date Format is directly inside **Date**, followed by week start and calendar
system. These controls are not in **Change Settings**. The Date popup displays
the global and current board defaults before your personal override.
