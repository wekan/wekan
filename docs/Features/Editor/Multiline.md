# Multiline titles and creating several items

In the new-card, new-list or new-swimlane name field, paste text containing
several nonempty lines. An **Add** chooser appears:

- **1 Card**, **1 List** or **1 Swimlane** keeps the whole text as one title
  containing line breaks. This is the default.
- The multiple-item count creates a separate item from each nonempty line.
  Blank lines are skipped and pasted order is preserved.

For example, paste:

```text
Plan the work
Build the feature
Check the result
```

Choose **3 Cards** to create three cards, or **1 Card** to keep a three-line
title. The same choice applies to lists and swimlanes. Use the form's Add/Save
button to submit. Card creation keeps the selected labels, members and other
creation options. Wait for creation to finish before submitting again.

List and swimlane rename fields also accept line breaks. Renaming always edits
the existing item; it does not split it into multiple items. Multiline names
are displayed in list/swimlane headers as well as on minicards.
