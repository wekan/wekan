# List menu / Select all cards in this list

List menu (☰ in the list header) → **Select all cards in this list** adds the
list's cards to the board's [Multi-Selection](../General/Multi-Selection.md)
and closes the menu. Whatever the Multi-Selection sidebar offers can then be
done to all of them at once.

## Who sees it

A board member who is not **Comment only**, **Read only** or **Read assigned
only**, and only when the list has cards.

## Which cards

- In the **Swimlanes** board view, a list shown in a swimlane selects only the
  cards of that swimlane ([#5623](https://github.com/wekan/wekan/issues/5623)).
- In the other views, every card of the list is selected.

Selecting changes nothing on the board by itself.
