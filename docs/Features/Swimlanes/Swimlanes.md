# Swimlanes

Swimlanes divide a board into horizontal bands. Choose **Swimlanes** in the
board-view menu to work with them. Each card belongs to a list and a swimlane;
lanes can contain their own lists as well as legacy shared lists.

## Create and rename

Use **+** beside a swimlane header to open **Add Swimlane**. Paste several lines
and use **Add** to choose one multiline swimlane name or one swimlane per
nonempty line. Save to create them in the pasted order. Click the name to rename
it; the editor and displayed title preserve line breaks.
See [multiline creation](../Editor/Multiline.md).

## Arrange and manage

Use the header drag handle where shown to reorder swimlanes. The caret
collapses/expands a lane, and its menu provides links/history, export/import and
permitted move/copy/archive actions. Resize with the lane's resize handle when
the board administrator has not locked resizing.
