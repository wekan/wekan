# Top header

The header provides the current page title and navigation, starred items,
creation controls, notifications and your username/avatar. Click your username
at the top right to open [Member Settings](../Member-Settings/README.md).
The notification bell opens received notifications; notification delivery
preferences are under Member Settings / Notifications.

On a board, the board controls include visibility, watching, sorting, filtering,
search, dependencies, multi-selection and the Board View chooser. Use
[Board Settings / Board View](../Board-Sidebar/Board-Settings/Board-View.md)
to configure which views appear and their order. That configuration requires
board administrator access.
