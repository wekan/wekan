# Board Settings / List

A board administrator can enable **Lock list width resize** and **Same width
for all lists** here. When resizing is permitted, drag the handle between
lists. The same-width setting applies a common width to the board's lists.

These switches moved from header controls into this popup. The list menu no
longer has a **Set width** entry. See [Lists](../../Lists/Lists.md) for creation,
multiline names, collapse state and list actions.
