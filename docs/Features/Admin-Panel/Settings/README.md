# Admin Panel / Settings

The panes of the Settings tab, in menu order. **Version** is first and is the pane
that opens with the Admin Panel.

| Menu path | Page | What it is |
| --- | --- | --- |
| Settings / Version | [Version.md](Version.md) | What this instance is running: WeKan, Meteor, Node, the database and how it is reached. |
| Settings / Visibility | [Visibility.md](Visibility.md) | What All Boards shows, the URLs, the product name and the logos. |
| Settings / Announcement | [Announcement.md](Announcement.md) | The instance-wide banner. |
| Settings / Accessibility | [Accessibility.md](Accessibility.md) | The accessibility page and its content. |
| Settings / Translation | [Translation.md](Translation.md) | Custom translation strings. |
| Settings / PWA | [PWA.md](PWA.md) | Custom head tags, web manifest and assetlinks.json. |
| Settings / Global Webhooks | [Global-Webhooks.md](Global-Webhooks.md) | Outgoing webhooks for the whole instance. |

Every pane opens with a heading that is its menu entry's own label, so the pane and
the row that opened it always say the same thing — see
[Left Menu](../../../Features/Page/Left-Menu.md).
