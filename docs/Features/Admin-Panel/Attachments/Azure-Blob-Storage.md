# Azure Blob Storage

Configure Enabled, Read, storage account name, write-only account key,
write-only connection string and container. Calculate File Counts reports Azure
attachment/avatar metadata, and Test Connection uses the currently entered
configuration.

Both views share the Global Admin methods and bounded fixed provider schema.
Unknown fields and types are rejected. Stored account keys and connection
strings are never returned; translated set markers replace them, and blank
secret inputs retain the current values.
