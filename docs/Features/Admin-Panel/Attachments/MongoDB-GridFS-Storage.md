# MongoDB GridFS Storage

Enable or disable reading files stored in MongoDB GridFS and calculate attachment
and avatar counts. Counts distinguish legacy CollectionFS records from current
MongoDB/Meteor-Files records so a migration cannot hide files in one format.

After files have moved away, **Run MongoDB Compact** can reclaim database space.
It is a potentially long blocking operation and is not started merely by reading
the pane. HTML4 exposes it as a signed explicit POST and renders each returned
node/collection result; the dispatcher refuses the operation on any other storage
route.

All reads and writes call the same Global Admin-only methods as Jade. The
same-URL test changes Read, calculates counts and verifies the compact control and
both renderers without running this CPU/storage-intensive maintenance operation.
