# S3 and MinIO Storage

Configure S3-compatible storage: Enabled, Read, endpoint, AWS region, bucket,
access key ID, write-only secret access key and path-style URLs. This supports
AWS S3 and compatible services such as MinIO. Calculate File Counts reports
attachment and avatar metadata assigned to S3; Test Connection checks the
currently entered values before they need to be saved.

Jade and Legacy HTML4 use the same Global Admin methods and fixed provider
schema. Values are trimmed and bounded; unknown fields and wrong types are
rejected. The server never returns the secret, and an empty secret field retains
the stored value. HTML4 places Test and Save in the same semantic fieldset so
both submit the visible current values.
