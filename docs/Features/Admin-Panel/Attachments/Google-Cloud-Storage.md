# Google Cloud Storage

Configure Enabled, Read, project ID, bucket, service-account key-file path and
write-only service-account JSON. Calculate File Counts reports GCS attachment
and avatar metadata. Test Connection submits the currently entered values.

The shared provider schema bounds every field and requires non-empty credential
JSON to parse as an object, not an array or scalar. The server never returns the
credential document; a translated set marker replaces it, and blank input keeps
the current secret. Both HTML4 and Jade call the same Global Admin operations.
