# WeKan on Rancher

[#632](https://github.com/wekan/wekan/issues/632). This page used to describe
Rancher 1 with Rancher Active Proxy and the `wekanteam/wekan:meteor-1.4` image.
Both are long gone. Current Rancher (v2.x) manages Kubernetes clusters, and on
Kubernetes WeKan is installed with its Helm chart.

## 1. Add the WeKan chart repository

In Rancher: **Apps → Repositories → Create**:

| Field | Value |
| --- | --- |
| Name | `wekan` |
| Target | HTTP(S) URL to an index generated by Helm |
| Index URL | `https://wekan.github.io/charts/` |

Or with Helm itself, against the cluster Rancher manages:

```bash
helm repo add wekan https://wekan.github.io/charts/
helm repo update
```

The chart's source, issues and releases are at
[wekan/charts](https://github.com/wekan/charts/tree/main/wekan), and it is listed
on [ArtifactHub](https://artifacthub.io/packages/helm/wekan/wekan). See also
[Helm](Helm/README.md).

## 2. Install

**Apps → Charts → wekan → Install**, in its own namespace. The values that
matter:

| Value | What to set |
| --- | --- |
| `root_url` (`ROOT_URL`) | The address people open WeKan at, e.g. `https://wekan.example.com`. WeKan builds every link from it |
| the image | `ghcr.io/wekan/wekan` with a release tag (`v12.41`) rather than `latest`, so an upgrade is a choice |
| the database | The default WeKan image runs **FerretDB v1** with its database in files under `WRITABLE_PATH` (`/data`), so give it a **persistent volume** there. A MongoDB you run yourself is set with `MONGO_URL` |
| ingress | Rancher's ingress (or Traefik, NGINX) with the cluster's certificate issuer, e.g. cert-manager with Let's Encrypt, for the host in `root_url`. WeKan listens on port 8080 in the container |

With Helm:

```bash
helm install wekan wekan/wekan --namespace wekan --create-namespace \
  --set root_url=https://wekan.example.com
```

The value names of a chart version are in its `values.yaml`
(`helm show values wekan/wekan`), which is the authority if it and this page
disagree.

## 3. Upgrade

**Apps → Installed Apps → wekan → Upgrade**, choosing the new chart version,
or `helm upgrade wekan wekan/wekan --namespace wekan --reuse-values`. Take a
backup first: Admin Panel → Attachments → Backup, or a copy of the volume.

## Without Kubernetes

For one host, [Docker Compose](README.md) is simpler: `docker-compose.yml`
in this repository runs WeKan with FerretDB and SQLite and needs no other
service.
