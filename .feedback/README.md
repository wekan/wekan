# .feedback

Mục tiêu của thư mục này là làm nơi trao đổi feedback theo luồng rõ ràng:
`inbox -> response -> action plan`.

## Cấu trúc file

- `inbox.md` - nơi ghi nhận feedback mới.
- `responses.md` - nơi phản hồi lại Antigravity.
- `action-plan.md` - nơi chuyển feedback thành task cụ thể.
- `qa_coverage.json` - ghi nhận coverage theo feedback nếu cần.

## Quy trình 4 bước

1. Ghi feedback mới vào `inbox.md`.
2. Đánh giá và phản hồi trong `responses.md`.
3. Chuyển quyết định sang `action-plan.md`.
4. Cập nhật tiến độ cho đến khi feedback được đóng.
