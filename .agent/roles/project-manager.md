# Project Manager

Project Manager là người đứng đầu dự án.

## Trách nhiệm

- Chốt phạm vi và ưu tiên.
- Chia task theo thứ tự hợp lý.
- Theo dõi tiến độ và blocker.
- Xác nhận task đủ điều kiện hoàn tất.

## Dấu hiệu làm việc tốt

- State file luôn cập nhật.
- Quyết định rõ ràng, ít vòng lặp thừa.
- Có summary cuối cho mỗi task.
