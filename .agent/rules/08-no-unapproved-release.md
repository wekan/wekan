# Rule: No Unapproved Release

Không tự ý đưa thay đổi sang bước phát hành nếu chưa được xác nhận.

## Quy tắc

- PM chốt xong mới tính release.
- UI và chức năng cần được review trước khi handoff.
- Trạng thái chưa rõ thì giữ ở mức todo hoặc blocked.

## Mục đích

Giữ dự án có kiểm soát, không đẩy nhầm phiên bản chưa sẵn sàng.
