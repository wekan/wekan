# Skill: Architecture and Modularization

## Mục tiêu

Thiết kế thay đổi theo hướng tách module, giảm phụ thuộc chéo và dễ bảo trì.

## Khi dùng

- Khi task chạm nhiều file hoặc nhiều lớp logic.
- Khi file hiện tại quá dài.
- Khi cần chia nhỏ dự án để tránh tràn context.

## Đầu ra

- Cấu trúc module rõ ràng.
- Điểm tách file hợp lý.
- Danh sách phần nên giữ riêng để không làm rối code.
