# Skill: Documentation and Handoff

## Mục tiêu

Ghi lại thay đổi để người sau đọc là hiểu và nhận task tiếp không bị đứt mạch.

## Khi dùng

- Sau khi hoàn tất implementation.
- Khi bàn giao cho PM hoặc tester.
- Khi cần cập nhật changelog hay state file.

## Đầu ra

- Notes ngắn, rõ.
- Hướng dẫn kiểm tra.
- Tóm tắt rủi ro và next step.
