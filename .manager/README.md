# State Management

Tất cả state được lưu trong `.manager/`.

| File | Purpose |
|------|---------|
| `current_task.md` | Task hiện tại |
| `requirements.md` | Output từ PO |
| `implementation.md` | Developer notes |
| `test-report.md` | Tester results |
| `ux-feedback.md` | UX findings |
| `iteration_log.md` | Lịch sử loop |
| `final_report.md` | Summary cuối |

## Quy ước

- Project Manager cập nhật state sau mỗi task hoặc mỗi lần task đổi pha.
- Developer chỉ ghi phần triển khai và quyết định kỹ thuật.
- Tester ghi kết quả kiểm thử và lỗi.
- UX ghi nhận phản hồi giao diện và chức năng từ góc nhìn khách hàng.
