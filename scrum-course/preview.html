Preview Bài 2 - Delivery workflow

Cột WIP Policy chính
Idea / Intake Không giới hạn Có nguồn, lý do và owner quyết định discovery.
Discovery 3 Làm rõ problem, user, value và risk trước khi refine.
Ready for Refinement 8 Có mô tả user/problem để team làm rõ acceptance criteria.
Ready for Sprint 10 Đã refine, nhỏ, có value và đủ điều kiện vào Planning.
Sprint Backlog Theo capacity Gắn với Sprint Goal và được team cam kết.
In Progress 3 Developer nhận việc, build và test local trước review.
Code Review 2 Pull request sẵn sàng review, pass hoặc trả về rework.
QA / Validation 3 Kiểm acceptance criteria, regression và risk.
Ready for Release 5 Pass DoD, release note/docs sẵn sàng nếu cần.
Done Không giới hạn Đã release hoặc deployable theo policy của team.

Definition of Ready

  • User hoặc customer segment rõ.
  • Business/user value rõ.
  • Có acceptance criteria và estimate sơ bộ.
  • Dependencies/risk đã được ghi lại.
  • Không còn câu hỏi lớn cản trở implementation.

Definition of Done

  • Acceptance criteria met và code reviewed.
  • Unit/integration tests pass nếu liên quan.
  • UI checked nếu có thay đổi UI.
  • Security/privacy checked nếu có dữ liệu nhạy cảm.
  • Deployable hoặc đã deployed theo policy.
