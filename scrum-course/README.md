## Quy ước file

- Mỗi bài tập là một file độc lập.
- Tên file theo dạng `NN-ten-bai-tap.md`.
- Mỗi file nên có đủ: mục tiêu, bối cảnh, yêu cầu, bài làm, kết quả, cải
  thiện tiếp theo và checklist hoàn thành.
